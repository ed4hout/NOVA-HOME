# NOVA Home

Futuristische HUD-launcher voor de tv, met streamingapps, HDMI-ingangen, klok en weer.

- **Sony Bravia / Google TV**: het Android-project in deze map. Elke push bouwt automatisch een APK; je vindt hem onder **Actions → laatste run → nova-home-apk**. Uitleg staat in [LEESMIJ.md](LEESMIJ.md).
- **LG (webOS)**: zie de map [`webos/`](webos/LEESMIJ.md).

De weergave staat in `app/src/main/assets/index.html` (Google TV) en `webos/index.html` (LG).
